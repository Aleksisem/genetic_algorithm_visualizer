# 🧬 Genetic Algorithm Visualizer
JavaFX приложение для визуализации генетического алгоритма. Запускает симуляцию, в рамках которой группа особей обучается добираться от точки А до точки Б. Разработано в рамках выполнения задания курсовой работы.

## Технологии
- JavaFX
- Scene Builder
- Java
- Maven
- JUnit и TestFX для тестирования

## Функциональные возможности
- Размещение точек старта и финиша
- Редактирование следующих параметров симуляции:
    - количество особей
    - количество генов
    - вероятность мутации
    - количество лучших особей для отбора в конце итерации
- Добавление препятствий
- Пропуск итераций для ускорения сходимости алгоритма

## Ход работы
Я начал работу с разработки графического интерфейса, содержащего необходимые поля ввода для работы и Canvas-элемент для отрисовки объектов симуляции. Затем были созданы контроллеры, которые отслеживают события взаимодействия с элементами интерфейса и canvas (нажатие на кнопки, движение мыши).

Для отрисовки особей на поле я начал разрабатывать классы моделей элементов Canvas, содержащие поля координат и размеры. Для отрисовки элементов был создан интерфейс, описывающие единственный метод - рисование элемента, а затем служебные классы для каждого типа элемента (прямоугольник или круг), реализующие данный интерфейс. 

Для логики симуляции был создан отдельный класс-контроллер, который управляется главным контроллером, связанным с пользовательским интерфейсом. Данный класс реализует инициализацию симуляции - создание новой группы особей, логику движения особей, логику алгоритма эволюции популяции в конце каждой итерации, запуск новой итерации, регистрация особей, дошедших до цели.

## Чему я научился
- MVC паттерн: я научился структурировать архитектуру приложения с использованием паттерна проектирования Model-View-Controller
- Парадигма ООП: применяя на практике полученные мною знания об ООП, я научился создавать наборы взаимодействующих между собой объектов, реализующих абстрактное описание.
- Создание GUI: я научился разрабатывать user-friendly пользовательский интерфейс с помощью Scene Builder и языка разметки FXML.
- Функциональное тестирование: для проверки работоспособности приложения я научился создавать Unit тесты с помощью библиотеки JUnit, а также тесты GUI с помощью TestFX.

## Сборка и запуск
Для сборки проекта необходимы:
- JDK версии 17 и выше
- сборщик проектов Maven.

Для запуска проекта в локальном окружении выполните следующие шаги:
1. Клонируйте репозиторий на локальную машину.
2. В корневом каталоге запустите `mvn javafx:run -f ./pom.xml` для сборки и запуска проекта.
